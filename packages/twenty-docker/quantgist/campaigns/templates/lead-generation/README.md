# Template — Lead Generation

Drive signups, demos, and CRM leads. Every post should include a trackable CTA.

## When to use

- Waitlist or signup pushes
- Demo booking for B2B/partners
- Free guide or resource gated on email

## Required customization

1. Set `id` and UTM `utm_campaign` in all links
2. `kpis.targets.crmLeads` — sync with Twenty CRM tagging
3. Funnel: at least one awareness/education post before conversion posts
4. Log leads in Twenty with `source=<campaign-id>`

## CRM handoff

QG_MARKETING logs campaign in Twenty after scheduling. QG_ENGAGEMENT_ANALYST compares Postiz link clicks to CRM lead count.
